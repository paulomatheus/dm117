# Catch me! 🕵️‍♂️

Projeto de jogo 2D desenvolvido para a disciplina **DM117 - Desenvolvimento de Jogos com Unity**, como parte da avaliação do curso de Pós-Graduação de **Cloud Computing e Desenvolvimento Mobile**.

## 📖 Sobre o Projeto

"Catch me!" é um jogo de plataforma 2D onde o jogador assume o papel de um detetive habilidoso. A missão é navegar por diferentes níveis de um prédio, superando obstáculos e desafios para encontrar e capturar um ladrão astuto que está sempre um passo à frente.

O projeto foi desenvolvido utilizando as técnicas e conceitos aprendidos na disciplina, abrangendo desde a criação de personagens e cenários até a implementação de scripts de controle e animações.

---

## ✨ Funcionalidades

- **Movimentação Completa do Player:** Controle preciso do detetive, incluindo andar e pular.
- **Animações Fluidas:** Animações para os estados do personagem: parado (Idle), andando (Walk) e pulando (Jump).
- **Objetivo Claro:** Encontrar o ladrão para concluir o jogo.

---

## 🛠️ Tecnologias Utilizadas

- **Engine:** [Unity](https://unity.com/)
- **Linguagem:** C#
- **Arte/Assets:** Assets da Unity Store e Outros desenvolvidos pelo grupo.

## 🚀 Como Executar o Projeto

Para rodar este projeto, você precisará ter o Unity Hub e uma versão compatível do Unity Editor instalada.

1. **Clone o repositório:**

```bash
    git clone [https://github.com/](https://github.com/paulomatheus/dm117.git)
```

1. **Abra o projeto no Unity Hub:**
    - Abra o Unity Hub.
    - Clique em "Add" ou "Open".
    - Navegue até a pasta onde você clonou o repositório e selecione-a.

2. **Abra a cena principal:**
    - Dentro do editor do Unity, na janela "Project", navegue até a pasta `Assets/Scenes`.
    - Dê um duplo clique no arquivo da cena principal (`MainMenu`).

3. **Execute o jogo:**
    - Clique no botão "Play" (▶️) na parte superior do editor.
